# 화방넷 메인페이지 리디자인

미술재료 전문 쇼핑몰 **화방넷의 메인페이지를 재구성한 웹 리디자인 프로젝트**입니다.

기존 화방넷이 보유한 다양한 미술재료와 콘텐츠를 바탕으로,
사용자가 메인페이지에서 상품과 작품, 재료 관련 콘텐츠를 자연스럽게 탐색할 수 있도록
정보 구조와 시각적 경험을 개선했습니다.

## Project Concept

**재료를 발견하고, 창작을 시작하는 곳.**

단순히 상품을 나열하는 메인페이지에서 벗어나
재료와 작품을 둘러보는 과정 자체가 새로운 창작의 시작으로 이어질 수 있도록 구성했습니다.

## Main Contents

- **HERO** · 미술재료를 활용한 비주얼과 브랜드 메시지
- **START YOUR ART** · 재료, 작품, 가이드에서 시작하는 탐색 인터페이스
- **MATERIAL PICKS** · 재료의 특징을 중심으로 한 상품 큐레이션
- **ARTWORK → MATERIAL** · 작품과 사용 재료를 연결하는 콘텐츠
- **BRAND & MATERIAL STORY** · 브랜드와 재료에 대한 이야기
- **COMMUNITY** · 사용자 작업과 창작 콘텐츠
- **B2B** · 학교·학원·기관을 위한 구매 서비스 안내
