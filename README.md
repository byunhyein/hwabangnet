# 화방넷 리디자인

화방넷의 상품 탐색과 콘텐츠 발견 경험을 재구성한 포트폴리오용 정적 웹사이트 프로젝트입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 별도 빌드 과정은 필요하지 않습니다.

## 현재 상태

- Desktop 메인페이지 구조 및 디자인 시스템 구현
- 제품, 작품, 브랜드 이미지는 모두 명시적인 `PLACEHOLDER`로 사용 중
- 실제 자산이 제공되면 `assets/products`, `assets/artwork`, `assets/images` 경로의 파일로 교체 예정
- 로고는 승인된 원본 자산 제공 전까지 임시 텍스트 워드마크를 사용

## 기술

- HTML5
- CSS3
- Vanilla JavaScript
