# Desktop Hero asset map

The Desktop Hero (`xl`, 1280px and above) uses these independently replaceable image assets.
They are temporary generated production-layout assets, not the supplied Hero screenshot.

| File | Placement role | Replacement guidance |
| --- | --- | --- |
| `hero-orange-paint-stroke.png` | Main orange glossy paint swipe | Wide transparent PNG, orange acrylic paint only |
| `hero-yellow-paint-tube.png` | Yellow paint tube | Transparent product cutout, 3/4 angle |
| `hero-blue-brush-marker.png` | Tall blue marker | Transparent product cutout, full marker visible |
| `hero-orange-pencil.png` | Orange colored pencil | Transparent sharpened-pencil cutout |
| `hero-wood-palette.png` | Wooden palette + paint dabs | Transparent oval palette, top/3/4 view |
| `hero-blue-paint-ribbon.png` | Blue curved paint stroke | Transparent 3D paint ribbon |

Keep each replacement as a transparent PNG or WebP with generous transparent margins; CSS in `css/responsive.css` controls its Desktop placement.
